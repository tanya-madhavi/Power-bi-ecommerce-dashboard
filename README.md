# Power BI E-Commerce Sales Dashboard

## 📌 Project Overview

This project is an interactive **E-Commerce Sales Dashboard created using Microsoft Power BI**. It helps analyze sales performance, identify top-performing brands and states, and generate meaningful business insights from the data.

## 🎯 Objective

The objective of this project is to analyze e-commerce sales data and transform it into meaningful insights that can help businesses understand sales performance and make better decisions.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Modelling
* Data Visualization

## 📊 Dashboard Pages

* **Dashboard** – Provides an overall view of sales performance using KPIs and interactive visuals.
* **Detail View** – Provides detailed analysis of sales across different dimensions.
* **Insights** – Highlights important business insights, trends, and patterns.
* **Mobile View** – Optimized dashboard layout for mobile devices.
* **Advanced Visuals & Narrative** – Uses advanced visuals and narrative elements to present insights effectively.

## 📈 Key Analysis

* Overall sales performance
* Sales by brand
* Sales by state
* Category-wise sales analysis
* Top-performing brands
* Comparison of sales across different segments
* Key business insights using Power BI visuals

## 🔑 Key Features

* Interactive dashboard
* KPI cards
* Filters and slicers
* Drill-through analysis
* Key Influencers
* Advanced Power BI visuals
* Mobile layout
* Interactive and user-friendly visualizations

## 💡 Key Insights

The analysis helped identify top-performing brands and states, understand sales patterns across different categories, and identify areas with comparatively lower sales performance.
